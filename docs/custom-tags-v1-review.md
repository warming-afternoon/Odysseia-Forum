## 执行

上传 JSON 至正式服项目 `data/custom-tags-v1.json`，部署包含导入器的镜像，先按 `docs/custom-tags-import.md` 备份并执行只读预检。
正式服的已存在/停用/软删除记录、DC 概念和已有关系可能产生额外冲突；本地结构检查通过不代表线上预检通过。
暂缓关系后续应使用独立关系清单补充：引用已导入标签与确认后的正式服父标签 ID，先预检再提交。
