## 查询检查

在迁移后的副本上，对绑定数量最多的标准标签执行有效绑定筛选、按帖子内部 ID 排序并取前 20 条的 `EXPLAIN (ANALYZE, BUFFERS)`，此次采样执行时间为 **0.117 ms**，规划时间为 **0.717 ms**。

这是本机、当前数据量、单条 SQL 的检查，不是完整搜索接口耗时，也不是百万帖子或千万绑定压测结果。搜索仍使用 `tag_binding` 的有效绑定索引，不因来源拆表增加对 `discord_tag_source` 的关联；来源表用于同步与展示。不能据此承诺正式服耗时或性能提升倍数。

## 正式服部署

停写并备份完整数据库后，使用现有迁移入口升级，再启动同一版本 BOT 和 API。不要重写已执行 revision，不需要删除数据库。前端需同步适配 `discord_sources` 数组、`binding_source` 权限判断和合并后的刷新错误，详见 [标签接口文档](custom-tags.md)。

新增迁移不支持自动拆分降级；需要回滚时恢复维护窗口完整备份，不能只恢复 `thread_tag_link`。
